# Changelog

All notable public changes to the Nosmai Effects SDK for Android are documented
in this file.

## 3.0.7-beta.3

- Improved beauty and virtual-makeup rendering for more natural, consistent results.
- Improved face-tracked makeup alignment during movement, pose, mirroring, and scale changes.
- Includes the GPU preview and processed-frame lifecycle improvements from the earlier 3.0.7 betas.
- Improved overall performance and runtime stability.

## 3.0.6

- Improved beauty filter quality and visual consistency.
- Added new built-in beauty filters.
- Improved overall performance and runtime stability.

## 3.0.5

- Added `armeabi-v7a` support for compatible 32-bit ARM Android devices.
- Improved beauty-effect consistency.
- Improved performance, stability, and reliability.
